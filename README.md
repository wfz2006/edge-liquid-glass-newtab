# Liquid Glass 新标签页

一个面向 Microsoft Edge 的 Manifest V3 新标签页扩展，把液态玻璃视觉、生产力小组件和跨网页收集板放在同一个工作台里。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 功能概览

- 液态玻璃风格的新标签页：可选材质预设、时钟、天气、搜索建议与搜索历史。
- 玻璃表面采用局部像素采样和独立裁剪层，卡片边缘保持圆角，拖动时保留折射效果并减少合成残影。
- 搜索框聚焦时会轻微舒展，失焦后平滑恢复；按钮、快捷方式图标和场景标签提供悬停、按下、选中与键盘焦点反馈，并遵守系统的“减少动态效果”设置。
- Bing、Google、DuckDuckGo 和自定义搜索引擎，可切换当前页或新标签打开结果。
- 多场景快捷方式：编辑图标和标签、拖动排序，并支持批量管理。
- 布局编辑模式：自由摆放搜索框、快捷方式和小组件，调整场景顺序，并可撤销上一步布局操作。
- 壁纸库：内置多张预设壁纸，也可添加图片、GIF 或视频；支持轮换壁纸和每日 Bing 壁纸。
- 日历视图：月视图、周视图、日程视图，以及本地 ICS 文件和公开 ICS 订阅。
- 待办、重复任务、到期提醒、番茄钟、今日目标、世界时钟和专注模式。
- 浏览器信息面板：收藏夹、历史记录、最近关闭的标签、打开的标签和标签组。
- 收集板：在新标签页或普通 HTTP(S) 网页的左侧边缘唤出，收集链接、图片和选中文本。
- 收集板支持搜索、标签、拖动整理、批量操作、重复保护、快捷键粘贴和右键菜单收藏。
- 新标签页与网页侧边栏共用收集数据，可导入/导出备份，并可选择使用浏览器同步。

内置的 14 张生成壁纸由项目维护者提供，文件清单见 [`assets/wallpapers/CREDITS.md`](assets/wallpapers/CREDITS.md)；壁纸与扩展源代码分开授权。

## 安装

### 从源码加载

需要 Microsoft Edge（或兼容的 Chromium 浏览器）。

```powershell
git clone https://github.com/wfz2006/edge-liquid-glass-newtab.git
cd edge-liquid-glass-newtab
```

1. 在地址栏打开 `edge://extensions`。
2. 开启右侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本仓库目录。
4. 打开一个新标签页即可使用。

扩展安装或重新加载后，已经打开的普通网页需要刷新一次，网页侧收集板内容脚本才会注入。Edge 的内部页面（例如 `edge://` 页面）不会注入收集板。

## 使用提示

- 新标签页：使用搜索框、快捷方式页面和右上角设置面板配置工作台。
- 收集板：把鼠标移到屏幕最左缘唤出，也可以把网页中的链接、图片或选中文本拖到左缘；打开收集板后按 `Ctrl+V` 可粘贴内容。
- 普通网页：可以使用页面左缘的收集板、右键菜单，或“收藏当前网页”按钮。
- 备份：在设置中使用“导出数据”保存 JSON 备份；迁移设备前建议先导出。
- 同步：开启“自动同步”后使用浏览器同步存储。同步空间有限，大图片或大量收藏仍建议保留本地导出备份。

## 本地开发与检查

项目不需要打包器，修改源码后可以直接在 `edge://extensions` 中重新加载扩展。测试使用 Node.js 内置测试运行器：

```powershell
# 运行全部回归测试（包括液态玻璃、拖动、同步和性能检查）
node --test tests/*.test.js

# 检查 JavaScript 语法
Get-ChildItem js -Filter *.js | ForEach-Object { node --check $_.FullName }

# 检查 manifest.json
node -e "JSON.parse(require('fs').readFileSync('manifest.json','utf8')); console.log('manifest valid')"
```

主要目录：

```text
newtab.html       新标签页结构
css/              新标签页与液态玻璃样式
js/app.js         新标签页功能与数据状态
js/content.js     普通网页收集板
js/background.js  Service Worker、右键菜单与浏览器 API
js/*-core.js      可复用的收集板与布局逻辑
js/search-motion.js 搜索框聚焦舒展与局部折射尺寸同步
tests/             Node.js 回归测试
```

## 数据、权限与隐私

- 用户设置、快捷方式、待办和收集内容默认保存在扩展本地存储中。
- 只有在设置中开启自动同步时，扩展才会使用浏览器同步存储；可以随时关闭并用导出文件备份。
- 搜索请求会发送到当前选择的搜索引擎；天气功能会访问天气服务；每日 Bing 壁纸会访问 Bing；ICS 订阅会访问用户提供的日历地址。这些网络请求只在使用对应功能时发生。
- 扩展请求网页内容脚本权限是为了在 HTTP(S) 网页上提供收集板和专注模式；不会注入浏览器内部页面。
- 本项目当前未包含显式统计 SDK 或第三方分析代码。安装公开扩展前，仍建议自行审阅权限和源码。
