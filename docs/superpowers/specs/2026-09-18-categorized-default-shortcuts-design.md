# 默认快捷方式分类升级设计

**日期：** 2026-09-18  
**状态：** 已获用户确认，待用户复核  
**范围：** 默认网站小卡片、默认页面分类、旧默认数据迁移

## 背景

当前新标签页只有一个“首页”，内置 6 个网站快捷方式。项目本身已经支持多页面、页签切换、卡片编辑和本地存储，因此本次升级只需要充实默认数据并利用现有页面能力，不新增一套页面管理机制。

## 目标

1. 让新安装用户打开新标签页时就拥有按场景组织的网站入口。
2. 将默认网站数量从 6 个扩展到多个常用类别。
3. 保护已有用户的自定义快捷方式、页面和布局数据。
4. 保持现有卡片编辑、拖动排序、页面切换和存储格式兼容。

## 默认页面与网站

默认页面顺序固定如下；每个页面的 `id` 使用稳定值，名称用于底部页签展示。

| 页面 | 默认网站 |
|---|---|
| 常用 | 百度、Bing、GitHub、哔哩哔哩、知乎、淘宝、京东、微信网页版 |
| 开发编程 | GitHub、GitLab、Gitee、Stack Overflow、MDN、npm、Docker、Vercel |
| 学习资料 | Wikipedia、Google Scholar、中国大学 MOOC、学堂在线、Coursera、edX、Microsoft Learn、W3Schools |
| 资讯社区 | 少数派、IT之家、36氪、澎湃新闻、Hacker News、Reddit、豆瓣、知乎 |
| 视频娱乐 | 哔哩哔哩、YouTube、Twitch、Steam、腾讯视频、网易云音乐、Spotify、豆瓣 |
| 工具效率 | Notion、Google Drive、腾讯文档、WPS、Canva、Figma、Trello、在线计时器 |
| AI 工具 | ChatGPT、DeepSeek、Claude、Gemini、Hugging Face、Perplexity、Poe、OpenRouter |
| 生活消费 | 淘宝、京东、美团、大众点评、携程、什么值得买、12306、高德地图 |

重复网站允许出现在不同场景页中，因为其入口语义不同；每个卡片仍然是独立对象，用户可单独编辑或删除。

## 数据结构与迁移

在全局状态中增加默认种子版本字段，例如 `seedVersion: 2`。默认状态的 `pages` 改为上述分类页面集合，并将 `activePage` 指向“常用”页。

规范化流程继续负责限制页面数量、卡片数量、名称长度和网址字段。新增迁移只在以下条件同时满足时执行：

- 存储中没有当前默认种子版本；
- 现有数据只有一个名为“首页”的页面；
- 该页面仍然包含原始 6 个默认卡片，名称和网址均未改变；
- 没有证据表明用户已经对默认快捷方式做过自定义。

满足条件时，将页面替换为新的分类页面集合，并将活动页设为“常用”。不满足条件时，保留用户现有 `pages`、`activePage`、布局、小组件和其他状态，只补齐缺失的版本字段。

旧版单页字段 `shortcuts` 的兼容迁移仍然保留；如果它正好代表旧默认数据，则继续进入分类迁移，否则保持原有单页内容。

## 代码边界

- 主要修改集中在 `js/app.js` 的默认数据、规范化和迁移逻辑。
- 不改变 `newtab.html` 的结构。
- 不改变 `js/liquid-glass.js`、收集板、天气、搜索和拖动实现。
- 不新增网络接口；网站卡片只保存名称和网址，favicon 仍由现有逻辑加载。
- 不改写用户导入/导出格式；导出的状态对象自然包含新的页面数据和版本字段。

## 验证方案

### 静态验证

- `node --check js/app.js`
- `node --check js/content.js`
- `node --check js/liquid-glass.js`
- 解析 `manifest.json`

### 行为验证

使用临时 Edge 配置加载扩展并检查：

1. 新默认状态包含 8 个分类页，活动页为“常用”。
2. 各分类页卡片数量和网址与设计表一致。
3. 旧的未修改默认数据可以迁移到分类页。
4. 已修改的旧数据不会被覆盖。
5. 页面切换、卡片编辑、卡片删除和拖动排序仍能工作。
6. 刷新新标签页后页面分类和活动页仍然保留。

## 非目标

- 本次不做卡片搜索、标签筛选、批量编辑或远程网站目录。
- 本次不改变用户已经创建的自定义页面。
- 本次不保证所有第三方网站在所有网络环境下都可访问；卡片只提供入口。
