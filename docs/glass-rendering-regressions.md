# 卡片折射回归检查

快捷方式拖到时钟旁时出现下方横带、背景边角提前出现在卡片内，
需要同时检查位移贴图的局部坐标和拖动后的画面，不能只检查滤镜属性存在。

## 坐标约定

`js/liquid-glass.js` 的普通卡片贴图由 `dispMap(W, H, ...)` 生成。
对应 `feImage` 必须使用 `x=0, y=0, width=W, height=H`，
配合 `primitiveUnits=userSpaceOnUse`。`100%` 按 SVG 视口解释，
不是这张卡片的宽高。调整材质预设、自由摆放和滤镜输出范围时，应保留这个约定。

2026-09-24 的 Chromium 像素对照中，百分比贴图把中部白色标记的中心从
`(59.5, 51.5)` 移到 `(50, 42)`；局部像素贴图消除了这个整体平移。
光学中心必须固定，但不能要求整片内部完全没有位移：那只会得到边缘棱线和
普通透明叠加，无法满足背景透过整块玻璃时可见偏折的要求。

内部使用朝光学中心的连续采样偏移，平滑过渡到边缘的 SDF 法线位移。
例如 120×104px 卡片的内部四分之一位置约偏折 3.7px，中心仍保持固定。
取样保持在卡片局部范围内，图标和文字本身不经过 backdrop 位移。

拖动继续使用 `LGDragPosition.apply()` 的 `left/top`，保留玻璃折射。
自由摆放的位置持久化、层级和跨场景移动无需为此回退。

## 自动检查

运行 `node --test tests/*.test.js`。
`liquid-glass-instance.test.js` 检查独立滤镜、局部像素范围、祖先缩放、lite 切换和尺寸变化。
`glass-interior.test.js` 检查内部有可见位移、中心固定、连续性和采样边界。

拖动首个移动事件切换为单路折射，仍使用相同的内部透镜贴图，停稳后恢复三路色散。
`LiquidGlass.lite()` 只同步更新传入元素，避免第一帧仍使用昂贵滤镜或扫描整页。
正常松手、指针取消、跨场景移动和提前结束拖动，都必须恢复原有材质。
拖动仍通过 left/top 定位，不使用 transform，也不禁用 backdrop-filter。

在仓库目录启动本地 HTTP 服务，例如：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

使用 Playwright 打开本地站点，再通过 `browser_run_code_unsafe` 的 `filename`
参数执行 `tests/browser/glass-sampling.probe.js`。
也可以把这个文件作为函数表达式交给现有 Playwright 测试运行器并传入 `page`。
它使用 `tests/fixtures/glass-sampling.html`，不写入生产页面存储。

探针覆盖三个材质预设的静态和拖动两种滤镜：

- 中心标记可以被透镜放大，但其重心与无位移参考画面的偏差不得超过 0.75px。
- 邻居位于上、下、左、右，间隔 4px 或 12px 时，改变邻居颜色不改变卡片截图。
- 实际重叠时，邻居颜色会改变玻璃画面。
- 边缘和排除边缘后的内部条纹，都必须在正常位移与位移为零时产生不同像素，区分真正折射与普通半透明叠加。

打开本地 `newtab.html` 后运行 `tests/browser/layout-stacking.probe.js`，
检查已有层级的卡片拖到搜索框上方时，在按住、松手、刷新后三种状态均在前方；
打开搜索菜单和设置时仍可操作。探针会恢复本地预览存储，不应用于真实扩展存储。
`layout-stacking.test.js` 覆盖重复置顶 130 次后的卡片、搜索框、小组件顺序，
避免层级封顶后并列；全局搜索框的层级还必须在数据规范化时保留。

把贴图尺寸临时改回 `100%` 时，探针应在中部标记检查失败。

## 页面与 Edge 验收

搜索历史打开动画会经过 `scale(.98)`。贴图必须使用 `offsetWidth/offsetHeight`
的局部布局尺寸，不能使用包含祖先缩放的 `getBoundingClientRect()`。
曾复现 640px 宽条目得到 627px 贴图，动画结束后右侧留下竖直接缝。
反复打开搜索历史，确认右端连续；条目不投外阴影，避免滚动区内阴影叠成灰黑底板。

用细条纹或细节密集的壁纸，将快捷方式拖到与时钟齐平的位置：
检查下方未移动卡片不产生横带，松手及刷新后自由位置保留。
再次拖到另一张卡片旁边，分别检查未重叠与真正重叠时的采样。
还应在用户实际 Edge 扩展和 GPU 环境复查；本地 Chromium 探针不能替代它。
